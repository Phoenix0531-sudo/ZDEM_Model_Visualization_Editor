# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-08

### Added
- Initial public release
- ZDEM model file parsing and visualization
- Support for WALL, GLINE, BOX, PROP P4 object types
- Interactive canvas with zoom, pan, and selection highlight
- Asynchronous file loading for large models
- Coordinate system with real-time status bar display
- LOD rendering and viewport culling for performance
